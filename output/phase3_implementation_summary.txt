PHASE 3 ENHANCEMENTS DETAILS
================================================================================

Cash Flow GAAP Mappings Added:
  - us-gaap:NetCashProvidedByUsedInOperatingActivities
  - us-gaap:NetCashProvidedByUsedInInvestingActivities  
  - us-gaap:NetCashProvidedByUsedInFinancingActivities

New Methods:
  - _parse_period_to_fiscal(period: str) -> tuple
    Converts "FY2024" -> (2024, None)
    Converts "Q1 2025" -> (2025, 1)
    
  - _calculate_cashflow_metrics(vital_signs: Dict) -> Dict
    Returns: operating_cash_flow_billion, investing_cash_flow_billion,
             financing_cash_flow_billion, operating_cash_flow_margin_percent
    
  - export_timeseries_json(output_path: str)
    Creates flat array structure optimized for charting
    Parallel arrays indexed by period for all metrics

New Fields in Filing Objects:
  - fiscal_year: int (e.g., 2024)
  - fiscal_quarter: int or None (1-3 for quarters, None for annual)
  - cashflow_metrics: dict with 4 metrics

Time-Series JSON Structure:
  {
    "metadata": {...},
    "periods": [{period, fiscal_year, fiscal_quarter, filing_type}],
    "metrics": {
      "revenue": {net_sales_billion: [...], yoy_growth_percent: [...]},
      "margins": {gross_margin_percent: [...], operating_margin_percent: [...]},
      "inventory": {inventory_billion: [...], turnover_ratio: [...], dsi: [...]},
      "debt": {total_debt_billion: [...], interest_coverage_ratio: [...]},
      "comparable_sales": {total_change_percent: [...], digital_change_percent: [...]},
      "cash_flows": {
        operating_cash_flow_billion: [...],
        investing_cash_flow_billion: [...],
        financing_cash_flow_billion: [...],
        operating_cash_flow_margin_percent: [...]
      }
    },
    "comparisons": {...},
    "risk_heatmap": {...}
  }
