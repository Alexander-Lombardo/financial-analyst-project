# Phase 3 Quick Reference Guide

**Status:** ✅ Complete (January 20, 2026)

## What's New in Phase 3

### 1. Dual Export Formats

**Detailed JSON** (`target_analysis.json`)
- Backward compatible with Phase 2
- Includes all historical data
- Nested structure with full context

**Time-Series JSON** (`target_timeseries.json`)
- Optimized for Plotly charting
- Flat array structure
- 65% smaller file size
- Perfect for data visualization

### 2. Temporal Keys

Every filing now includes:
- `fiscal_year` (int): e.g., 2025
- `fiscal_quarter` (int or None): 1-3 for quarters, None for annual

### 3. Cash Flow Analysis

New metrics extracted from SEC filings:
- `operating_cash_flow_billion`
- `investing_cash_flow_billion`
- `financing_cash_flow_billion`
- `operating_cash_flow_margin_percent` (calculated)

### 4. Interactive Visualizations

5 Plotly charts generated by `visualize_data.py`:

| Chart | Filename | Description |
|-------|----------|-------------|
| 1 | chart_revenue_vs_inventory.html | Dual-axis line chart |
| 2 | chart_operating_margin_waterfall.html | Quarterly trend with baseline |
| 3 | chart_inventory_efficiency.html | Turnover (bars) + DSI (line) |
| 4 | chart_debt_health.html | Coverage ratio + Total debt |
| 5 | chart_cash_flows.html | 3 lines (operating, investing, financing) |

## Usage Examples

### Reading Time-Series JSON

```python
import json

with open('output/target_timeseries.json') as f:
    data = json.load(f)

# Get all periods
periods = data['periods']
# [{'period': 'FY2020', 'fiscal_year': 2020, 'fiscal_quarter': None, ...}, ...]

# Get revenue data
revenue = data['metrics']['revenue']['net_sales_billion']
# [92.4, 104.611, 106.005, ...]

# Get cash flows
cash_flows = data['metrics']['cash_flows']
operating_cf = cash_flows['operating_cash_flow_billion']
# [10.525, 8.625, 4.018, ...]
```

### Creating Custom Charts

```python
import plotly.graph_objects as go
import json

# Load data
with open('output/target_timeseries.json') as f:
    data = json.load(f)

# Extract data
periods = [p['period'] for p in data['periods']]
revenue = data['metrics']['revenue']['net_sales_billion']

# Create chart
fig = go.Figure()
fig.add_trace(go.Scatter(x=periods, y=revenue, mode='lines+markers'))
fig.update_layout(title='Revenue Trend')
fig.write_html('custom_chart.html')
```

## New Code Components

### Methods Added to `financial_analyzer.py`

1. **`_parse_period_to_fiscal(period: str) -> tuple`**
   - Parses period strings to (fiscal_year, fiscal_quarter)
   - Handles "FY2024" → (2024, None)
   - Handles "Q1 2025" → (2025, 1)

2. **`_calculate_cashflow_metrics(vital_signs: Dict) -> Dict`**
   - Extracts cash flow data from vital_signs
   - Calculates operating CF margin
   - Returns 4 metrics

3. **`export_timeseries_json(output_path: str)`**
   - Creates flat array structure
   - Organizes metrics by category
   - Optimized for charting libraries

### New File: `visualize_data.py`

Functions:
- `load_timeseries_data()` - Loads time-series JSON
- `create_revenue_vs_inventory_chart()` - Chart 1
- `create_operating_margin_waterfall()` - Chart 2
- `create_inventory_efficiency_chart()` - Chart 3
- `create_debt_health_chart()` - Chart 4
- `create_cash_flows_chart()` - Chart 5
- `main()` - Generates all 5 charts

## Known Limitations

1. **Sparse Debt Data** (Expected)
   - Quarterly 10-Q reports don't always include detailed debt
   - Only 3 of 17 periods have complete debt data
   - This is normal SEC filing behavior

2. **Empty Comparable Sales** (Expected)
   - 7 older annual reports have empty comparable_sales
   - Historical data format differences
   - Not a bug
